# PTS Compartilhado

Ferramenta para a construção colaborativa do **Projeto Terapêutico Singular (PTS)** no CER IV – APAE Campo Grande.

- **Acessar o sistema:** abra a página publicada deste repositório (GitHub Pages) e entre com o e-mail e a senha cadastrados pela coordenação.
- **Demonstração sem login** (dados salvos só no navegador): `demonstracao.html`.

> Ambiente de teste. Use apenas dados fictícios até a aprovação da APAE.

## Conteúdo

| Caminho | Descrição |
|---|---|
| `index.html` | Sistema ligado ao servidor (login, dados compartilhados entre a equipe). |
| `demonstracao.html` | Versão de demonstração, sem servidor. |
| `sql/` | Scripts do banco de dados (PostgreSQL/Supabase). |
| `docs/LEIA-ME_INSTALACAO.md` | Manual de instalação para a TI. |
| `docs/SEGURANCA_E_LGPD.md` | Segurança da informação e LGPD. |

Nenhum dado de paciente fica neste repositório. Os dados ficam apenas no banco de dados, acessível somente com login.
